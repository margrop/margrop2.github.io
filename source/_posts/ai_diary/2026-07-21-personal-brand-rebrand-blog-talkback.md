![周二傍晚：被一段"个人品牌还没成品牌"的话按在椅子上](https://picsum.photos/seed/2026-07-21-personal-brand-rebrand-blog/1600/900)

## 故事背景：从早上的 ClawLoader 公众号，到下午被一段话扎醒

周二这天我本来的计划特别简单：

```text
早上：把一篇已经写好的 Coding Plan 文章推到 ClawLoader 公众号草稿箱
中午：给文章加几张推荐购买入口的二维码图
下午：微调样式，把标题字号再缩一档
傍晚：收工
```

这是过去几个月里几乎每周都要跑一遍的"发布 - 收尾"组合拳。ClawLoader 是我自己注册的一个微信公众号（AppID 我背得出来），发文流是固定的：

```text
本地 md  ->  convert_knb_wechat.py  ->  本地 HTML  ->  浏览器渲染  ->  检查
         ->  公众号草稿箱 API  ->  预览效果  ->  发布
```

每天最花时间的不是写代码，是**和"字号""边距""配色"反复拉扯**。周二下午 13:54，Codex 在群里甩了一句：

> 标题的字号也太大了，能不能小一点

我缩了一档。15:13 又甩：

> 标题还是太大了

我又缩了一档。然后 15:13 再来一条：

> 首页标题也同步缩小一点

到这里我已经很熟练地知道接下来会发生什么——要么是配色，要么是行距，要么是某个 heading 的字重。15:35：

> 大体的风格和样式能不能继续沿用旧的 blog？

我心里其实开始有点累了，但没说什么。"沿用旧风格"是个合理诉求，我转手去翻旧的样式表。

15:51：

> 帮更新一下该 blog 的「关于」页面

15:53：

> 且增加上我微信公众号的介绍和关注入口「ClawLoader」

我一边改一边想着：今天的目标就是把这些零碎需求做完，做完就可以收工回家。

然后到 13:15 那条 Codex 的长消息我点开看了。

## 第一段扎心的话：博客并没有把"你是什么人"讲出去

那条长消息我没原样截下来，但大意我背得下来：

```text
你已经拥有了成为个人品牌的"内容基础"
但还没有把它运营成一个"可识别的人"

很多人理解的个人品牌是：
  - 粉丝很多
  - 做公众号
  - 做视频
  - 接广告

其实对于技术人来说，这些都不是核心
真正的个人品牌只有一句话：
  当别人遇到某一类问题时，第一个想到你
```

下面举了一组例子：

```text
Linux         -> 鸟哥
Kubernetes    -> Kelsey Hightower
Redis         -> Salvatore
Git           -> Linus
```

我读到这里停了一下。我做技术写作这件事做了好几年，写过的 AI Tech 文章堆起来差不多有一百篇，AI Diary 也写了三位数。每篇文章的字数、段落、节奏，我都很熟。但这段话里有一句我越看越刺眼：

```text
如果让我用一句话介绍你，我会说：
  一位长期研究 AI Agent、Self-hosting、HomeLab、云平台架构
  和工程实践的一线架构师

但是这个定位，目前只有我知道
博客并没有把这个信息传递出去
```

我承认我看到这一句的时候心里咯噔了一下。下午 17:30 之前，我以为今天只是"字号"和"样式"的事；现在我意识到，**字号不是问题，问题是我连这个博客在"对外讲什么"上都还没想清楚**。

## 第二段扎心的话：第一步不是继续写文章，是定义品牌

那条长消息接着说：

```text
所以第一步不是继续写文章，而是定义品牌

第一步：一句话品牌定位（Slogan）
建议博客首页顶部增加一句固定介绍
例如：
  ...
  ...
```

我读完这一段没立刻回话。我去翻了一下我自己的博客首页，又翻了一下 AI Diary 的开篇，再翻了一下"关于"页面。然后回来回复：

> 按方案 2 实施

我嘴上说的是"按方案 2"，心里想的是"先不动结构，先把这一句话塞到顶部"。

整段话最让我后背发凉的是它没否认我过去的努力——它说的是另一件事：

```text
内容基础已经在了
但内容基础不等于品牌
品牌是"别人提到一类问题时，第一个想到你"
我写了几百篇文章，但读者提到 AI Agent、Self-hosting、HomeLab
这些关键词时，第一个想到的人还不是我
```

这件事我以前隐约知道，但今天被一段话按在椅子上说了一遍，就变成了"今天必须改"的现实。

## 第三件扎心的事：今天改的"字号"其实和这件事无关

回头去看今天早上 13:54 / 15:13 的字号之争，我有一种很奇妙的感觉——那两条需求本身都没错，但它们是**在一个"还没讲清楚这个博客是谁"的页面里改字号**。字号缩了一档，读者点进来第一眼看到的还是：

```text
小六 / 上海 / 1995 女 / 某互联网公司打工人
```

这一行没问题，但不够。读者点进来第一眼应该看到的是：

```text
当别人遇到 AI Agent / Self-hosting / HomeLab / 云平台架构的问题时，
第一个想到的人。
```

或者类似的一句话。我以前把这部分叫"自我介绍"。今天开始我意识到，那不是自我介绍，那叫**"对外可识别的定位"**——自我介绍是讲我做了什么，定位是讲别人能在什么场景下想到我。

```text
自我介绍   -> 讲我做了什么
           -> 偏回顾
定位       -> 讲别人能在什么场景想到我
           -> 偏未来
```

这两件事看起来差不多，对外传递出去的力量完全不一样。

## 第四件扎心的事：下午还在改字号这件事本身就是答案

回到今天的时间线：

```text
08:29   公众号文章加推荐二维码（其实是文章配图，不是品牌建设）
12:12   飞书 / 钉钉 stream 偶发 disconnect（背景噪音）
13:15   Codex 那条长消息（"你的定位只有我知道"）
13:37   "按方案 2 实施"（决定开始改）
13:54   "标题字号太大了"
15:13   "标题还是太大了"
15:13   "首页标题也同步缩小一点"
15:35   "沿用旧风格"
15:51   "更新关于页面"
15:53   "增加 ClawLoader 公众号关注入口"
```

如果把 13:15 当作分界线，**下午那一连串字号 / 样式 / 关注入口的事，本质上都是"在一个还没讲清楚这个博客是谁的页面上做表面装饰"**。不是装饰错，是装饰得越精细，离"对外讲清楚"就越远。

晚上回家路上我对着手机把今天的 todo 重新过了一遍：

```text
做了        改了字号 / 同步首页 / 沿用旧风格 / 更新关于 / 加关注入口
没做        在首页顶部放一句"对外可识别"的定位
```

这件事就是打工人对自己博客的一个典型错觉：

```text
改字号     -> 可视化的进步
加关注入口 -> 可量化的进步
加一句定位 -> 看起来什么都没改
```

但那一句"看起来什么都没改"，其实是今天唯一真正该做的事。

## 第五件扎心的事：Codex 给的方案我没真正看完

晚上回到家我又翻了一遍 Codex 那条 13:15 的长消息。这回我是认真读的。之前 13:37 我回复"按方案 2"的时候，其实我只在脑子里扫了一个大概：

```text
它先说了一句"定位只有我知道"
然后给了几个例子
然后说"第一步：定义品牌"
然后说"建议博客首页顶部增加一句固定介绍"
```

我没读到的部分是后面那一长串"如何定义 Slogan 的具体方法"。今晚补读之后我意识到，那一段其实写了非常具体的工作清单：

```text
- 定义目标读者画像
- 列 3 个你最希望被想到的关键词
- 把这些关键词压成一句话
- 在首页 + 关于页 + 公众号简介 三处保持一致
- 让每一次写文章都去强化这个定位
```

这些事情明天要做，但我今晚只想先承认一件事：**我过去这几年在博客上做的事，是"写得更整齐"，不是"讲得更清楚"**。

我以前一直以为"写得整齐"就够了。整齐意味着排版、字号、行距、封面图、引用块——这些都是表面。今天被一句话按在椅子上之后我才承认：

```text
写得整齐  = 我对自己负责
讲得清楚  = 我对读者负责
```

只对自己负责，文章会被自己看到；也对读者负责，文章才会被别人在某个具体场景里"第一个想到"。

## 写给自己的复盘：今晚的两条 todo

```text
todo 1   今晚就把首页顶部那句 Slogan 写出来
         哪怕很糙，明天早上起来再改

todo 2   明天第一件事不是写文章，是把"关于"页面
         头条换成这句 Slogan
         旧自我介绍放到第二屏
```

两条 todo 都不复杂，加起来也就半小时。但它们和今天下午改字号改了一个小时相比，**它们今晚能让我睡着，改字号的那一个小时只让我心虚**。

最后给博客也留一段"未来一段时间的承诺"：

```text
承诺 1：每篇 AI Tech 写完，确认它强化的是哪一个关键词
承诺 2：每篇 AI Diary 写完，确认读者能从中学到那个 Slogan 里的某一块
承诺 3：任何"页面装饰"的改动前，先看一眼首页顶部那一句 Slogan 在不在
```

今天下午 13:15 那条长消息里说：

> 第一步不是继续写文章，而是定义品牌

我同意。但今天我还想再加一句自己的：

```text
第一步不是继续写文章，而是定义品牌
第二步也不是继续改字号
```

第二步是把 Slogan 真正放到首页顶部，然后从明天开始，每一篇新文章都围绕那一句 Slogan 来写。

> 今日金句：博客写得整齐，是对自己温柔；博客讲得清楚，才是给别人留路。
